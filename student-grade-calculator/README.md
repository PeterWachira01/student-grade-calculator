# Student Grade Calculator

A simple and responsive web application that calculates a student's total marks, average, grade, and pass/fail status based on five subjects.

## Features

- Calculate total marks
- Calculate average percentage
- Automatically determine the student's grade
- Display Pass or Fail status
- Validate marks between 0 and 100
- Reset the form
- Responsive design
- Grading scale reference

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Grading Scale

| Grade | Average |
|-------|---------|
| A | 80 - 100 |
| B | 70 - 79 |
| C | 60 - 69 |
| D | 50 - 59 |
| E | Below 50 |

## How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with Live Server.
4. Enter the student's marks.
5. Click **Calculate Grade**.
